# Alpha Advisory

React-сайт по шести предоставленным скриншотам. Разработан в текущем рабочем проекте «Сайт по Финансам»; файлы в папке исходников Alpha Advisory не изменялись.

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://localhost:5173.

```sh
npm run build
npm run preview
npm test
```

`dist/` — готовая статическая сборка для хостинга. Для браузерных тестов используется установленный Google Chrome.

## Что реализовано

- Шесть секций, закреплённая навигация с активным разделом и мобильное меню.
- Английские тексты из скриншотов, шесть услуг, квалификации и контакты.
- Исходная фотография основателя и подготовленные изображения героя и дерева. Заголовки, подписи и кнопки — отдельные HTML-элементы.
- Интерактивный глобус Three.js: объёмная сфера, приподнятые материки, фактура камня и сетка координат в цветах исходного изображения. Медленное автовращение, перетаскивание мышью/пальцем с плавно затухающей инерцией после отпускания, стрелки клавиатуры и Home для возврата исходного ракурса. `prefers-reduced-motion` выключает автовращение по умолчанию.
- 3D-модуль загружается при приближении к блоку и прекращает отрисовку вне экрана. При отсутствии WebGL показывается исходная картинка. Геометрия Земли восстановлена по Natural Earth через `world-atlas` (ISC), а не извлечена из единственного ракурса фотографии.
- Плавная прокрутка, анимация появления и наведения; поддержка `prefers-reduced-motion`, клавиатурной навигации и подписей полей.
- Кнопки переходят к форме. Выбранная услуга подставляется в сообщение. Ссылки LinkedIn ведут на профиль, сохранённый в материалах проекта.
- Проверка обязательных полей и email, состояния ожидания и ошибки, сохранение введённых данных при ошибке.

## Подключение доставки заявок

Адрес получения заявок в материалах не указан. Пока endpoint не настроен, форма честно сообщает, что сообщение не отправлено, сохраняет данные и предлагает LinkedIn.

Создайте `.env.local`:

```dotenv
VITE_CONTACT_ENDPOINT=https://your-domain.example/api/contact
```

Это пример формата, не рабочий адрес. Укажите реальный URL своего обработчика и пересоберите проект. Клиент отправляет JSON методом POST: `{ name, email, company, message }`. Обработчик должен принимать этот формат и возвращать HTTP 2xx только после принятия заявки; для другого домена необходим CORS. Серверная доставка, хранение заявок и защита от спама настраиваются в этом обработчике. Секретные ключи нельзя размещать в `VITE_*`.

Реальная отправка не проверялась: получатель не предоставлен.

## Файлы

- `src/App.jsx` — секции, навигация и общие элементы.
- `src/content.js` — услуги, этапы и адрес LinkedIn.
- `src/ContactForm.jsx` — форма и отправка.
- `src/Globe.jsx` — загрузка 3D-сцены, управление и резервное изображение.
- `src/globeScene.js` — материалы, географическая текстура, освещение и взаимодействие с Three.js.
- `src/styles.css` — оформление, адаптивность и анимации.
- `public/assets/` — предоставленные изображения.
- `tests/site.spec.js` — браузерные проверки.
- QA-снимки и временные материалы не входят в исходный проект.

Макеты имеют растровую типографику; в реализации используется близкая системная антиква Times New Roman и локально подключённый Inter. При отсутствии Times New Roman браузер использует Times/Liberation Serif/serif. На телефоне секции перестраиваются в одну колонку.
